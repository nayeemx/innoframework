Reference inno CLI

CLI reference

The inno CLI is a single signed Rust binary. No Node.js required. Commands: init, dev, build, docs.

Overview

Install:

cargo install innoframework-cli

Check version:

inno --version

inno init

Scaffold a new Innoframework project with a manifest, routing, and CSP-safe stylesheet.

inno init --name my-app [-y]
FlagTypeDescription
--name, -nstringProject name (lowercase, ASCII, digits, dashes).
--yes, -yflagSkip interactive wizard, use defaults.

Generates:

  • inno.toml — project manifest
  • Cargo.toml — Rust crate with Dioxus 0.7
  • src/main.rs — entry point with asset!("/assets/inno-ui.css") + document::Stylesheet
  • assets/inno-ui.css — shared stylesheet (breakpoints 360/768/1280, focus-visible, reduced-motion)

Web only. The generated manifest uses dioxus = { version = "0.7", features = ["web"] } with no dioxus-router. File-based routing is automatic.

inno dev

Start the development server serving the Dioxus public directory with CSP + nosniff headers on every response.

inno dev [--port PORT]
FlagTypeDefaultDescription
--port, -pu168080Port to listen on (127.0.0.1 only).

Headers. Every response includes Content-Security-Policy and X-Content-Type-Options: nosniff. Path traversal is rejected.

inno build

Build for a target platform.

inno build <target>
TargetCommandDescription
webinno build webReal dx build --platform web --release, emits csp-header.txt.
desktopinno build desktopGenerates Tauri project files + cargo tauri build.
mobileinno build mobileRequires signing identity (AUD-3013), runs cargo tauri build --target.

Build for web

inno build web

Output: target/dx/<app>/release/web/public/ with index.html, WASM bundle, and csp-header.txt.

Build for desktop

inno build desktop

Generates src-tauri/tauri.conf.json and capability JSONs from manifest capabilities, then runs cargo tauri build. Unsigned (ADR-09 deferred).

Build for mobile

inno build mobile

Requires signing-identity in inno.toml. Generates mobile-specific Tauri config and runs cargo tauri build --target <bundle-target>.

inno docs

Generate markdown documentation from Rust source files using syn parsing.

inno docs [--source DIR] [--output FILE]
FlagTypeDefaultDescription
--source, -sstring.Directory to scan for Rust source files.
--output, -ostringstdoutOutput file path (prints to stdout if omitted).

AUD error catalog

All CLI errors carry a stable AUD code, a user-facing message (no secrets), a fix suggestion, and a doc link.

CodeConditionFix
AUD-3001Init directory already existsChoose a different name or remove the directory
AUD-3002Invalid platform in init wizardChoose web, desktop, or mobile
AUD-3003No inno.toml manifest foundRun inno init first
AUD-3004Secret embedded in manifestRemove credential; use environment variables
AUD-3005Dev port already in useChoose a different port with --port
AUD-3006Unknown build targetUse web, desktop, or mobile
AUD-3007Template file missingCheck file permissions and disk space
AUD-3008Rust toolchain too oldrustup update
AUD-3009cargo tauri not foundcargo install tauri-cli --version 2.11.4
AUD-3010Manifest lacks desktop targetAdd "desktop" to targets
AUD-3011cargo tauri build failedFix compile errors, re-run
AUD-3012Manifest lacks mobile targetAdd "mobile" to targets
AUD-3013Mobile build needs signing identitySet signing-identity in inno.toml
