Security first. Innoframework is default-deny: every platform API call must be declared in your manifest. Undeclared calls are denied at runtime. Build-time checks reject secrets embedded in manifests or config before they ever ship.

Platforms

PlatformStatusBuild commandNotes
Web (WASM) Ready inno build web Compiles via dx build --platform web --release, emits CSP header.
Desktop (Tauri 2) Ready inno build desktop Generates Tauri project files, runs cargo tauri build. Unsigned (ADR-09 deferred).
Mobile (Tauri 2) Tooling inno build mobile Requires signing identity (AUD-3013). Store publishing deferred (ADR-13).
