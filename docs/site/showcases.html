Showcases

Reference applications demonstrating Innoframework capabilities across web, desktop, and mobile platforms.

Overview

Each showcase is a complete, buildable application with an inno.toml manifest, Cargo.toml, Dioxus 0.7 source, and CSP-safe stylesheet. They live in the showcases/ directory of the repository.

Showcase #1 — Web

showcases/showcase1/

Target: Web (WASM)

Demonstrates: Typed server functions (#[server]), auth guards, default-deny security, CSP presets, file-based routing.

Key files:

  • inno.toml — manifest with targets = ["web"]
  • Cargo.toml — Dioxus 0.7 with features = ["web"]
  • src/main.rs — Dioxus app with #[server] typed server function
  • assets/inno-ui.css — CSP-safe stylesheet

Build:

cd showcases/showcase1
inno build web

Showcase #2 — Desktop

showcases/showcase2/

Target: Desktop (Tauri 2)

Demonstrates: File system capabilities (fs.read, fs.write), notifications, auth guards, signing identity declaration.

Key files:

  • inno.toml — manifest with targets = ["desktop"], signing-identity, fs capabilities with path prefixes
  • Cargo.toml — Dioxus 0.7 with features = ["desktop"]
  • src/main.rs — Tauri desktop app with LaunchBuilder::desktop()
  • assets/inno-ui.css — desktop-optimized stylesheet

Build:

cd showcases/showcase2
inno build desktop

Signing deferred (ADR-09). Bundle is unsigned. Set signing-identity in inno.toml when a certificate is available.

Showcase #3 — Mobile

showcases/showcase3/

Target: Mobile (Tauri 2, Android)

Demonstrates: Mobile capabilities (keychain.get, keychain.set, dialog.open, dialog.save), signing identity, mobile target selection.

Key files:

  • inno.toml — manifest with targets = ["mobile"], mobile-target = "android", signing-identity
  • Cargo.toml — Dioxus 0.7 with features = ["mobile"]
  • src/main.rs — Tauri mobile app with LaunchBuilder::mobile()
  • assets/inno-ui.css — mobile-optimized stylesheet (touch targets, reduced-motion)

Build:

cd showcases/showcase3
inno build mobile

Signing required. Mobile builds fail with AUD-3013 unless signing-identity is set in inno.toml. Store publishing deferred (ADR-13).
