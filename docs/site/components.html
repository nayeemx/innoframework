Components

The Innoframework UI kit (Dioxus 0.7) provides accessible, server-side-renderable components with focus-visible styling, 44px touch targets, and reduced-motion support.

Overview

All components are Dioxus 0.7 components with SSR support via dioxus-ssr. They render semantic HTML with ARIA attributes and follow the design tokens (colors, spacing, motion) defined in innoframework-ui::tokens.

Accessibility baseline. All components meet MIN_CONTRAST_NORMAL=4.5:1 contrast and MIN_TOUCH_TARGET_PX=44 touch targets. :focus-visible rings are styled with --inno-focus-ring. prefers-reduced-motion: reduce disables animations.

Buttons

ComponentPropsAccessibility
Button label, disabled, button_type aria-disabled when disabled, native <button>
Link href, children Native <a> with href
Button example
Button {
    label: "Submit".to_string(),
    disabled: false,
    button_type: "submit".to_string()
}

Input {
    id: "email".to_string(),
    label: "Email".to_string(),
    autocomplete: "email".to_string()
}

Dialogs & popovers

ComponentPropsAccessibility
Dialog id, open, children hidden + aria-hidden when closed, honors open state
Popover id, trigger_label, open, children aria-expanded, aria-controls linking trigger to content
Tooltip id, label, children ARIA-describedby association
Dialog example
Dialog {
    id: "confirm".to_string(),
    open: true,
    "Are you sure?"
