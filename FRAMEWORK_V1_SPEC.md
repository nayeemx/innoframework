# Framework v1 — TypeScript Fullstack (Spec)

## Purpose
A minimal fullstack framework layer on top of Vite React for fullstack TypeScript apps. Owns routing, typed server functions, auth guards, CSP presets, and build-time secret checks. Everything else is out of scope for v1.

## Scope (in-scope)
- File-based routing with TanStack Router or Vite-generated route table
- Typed server functions: client calls look like local functions, run server-side, with generated client stubs
- One auth guard: every server function and route requires an authenticated session; unauthenticated calls fail closed
- Default CSP header preset: no `unsafe-inline`, `frame-ancestors: none`, minimal connect-src
- Build-time secret check: fail build if server env/secrets are bundled into client code
- Generated docs: API reference from JSDoc/type annotations in the slice code
- Tests required for every feature: unit + negative (unauth access fails, secrets leak blocked, hydration mismatch detected)

## Out of scope (explicitly deferred)
- Rust, Go, Python, WASM runtimes (v3)
- AI agent orchestration (v2)
- Cross-platform desktop/mobile shells (later)
- Real-time socket layer, WebRTC, MQTT
- Multi-database ORM abstraction
- Plugin marketplace

## Threat model (top risks to test)
1. RPC call without valid session → must fail with 401
2. Server-only module imported by client code → build must fail
3. User-controlled output rendered into HTML → CSP must block inline scripts; output must be escaped
4. Build-time secret string present in client bundle → build must fail

## Open question (decide before coding)
Routing library: TanStack Router (already used in Open_Erp) vs file-system routes generated by Vite plugin. TanStack Router gives typed search params and loaders out of the box; Vite-generated routes give less boilerplate but no type-safe search params.
